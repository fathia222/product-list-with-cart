# Product List with Cart

A responsive dessert ordering page built for the [Frontend Mentor](https://www.frontendmentor.io) “Product list with cart” challenge. Users can browse desserts, add them to a cart, change quantities, and confirm an order.

## Features

- Product cards generated from a `products.json` file using `fetch`
- Responsive images that switch between mobile, tablet and desktop sizes using the `<picture>` element
- **Add to Cart** button that turns into a `− 1 +` quantity control once an item is added
- Image border highlights in rose when an item is in the cart
- Cart panel showing each item, quantity, unit price, line total, item count and order total
- Remove an item from the cart with the × button
- Empty-cart illustration that hides once something is added
- **Confirm Order** button that opens an “Order Confirmed” popup with an order summary
- **Start New Order** button that clears the cart and resets every card
- Layout split into 5 columns on large screens: 3 for products, 2 for the cart

## Built With

- HTML5
- [Tailwind CSS v3](https://tailwindcss.com)
- Vanilla JavaScript (ES6)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) installed
- VS Code with the **Live Server** extension

### Installation

1. Clone or download the project and open the folder in VS Code.
2. Install the dependencies:
   ```bash
   Npm install
   ```
3. Start the Tailwind build in watch mode and leave it running:
   ```bash
   Npx tailwindcss -i ./input.css -o ./dist/output.css –watch
   ```
4. Right-click `index.html` and choose **Open with Live Server**.

The page must be served through Live Server (or another local server). Opening `index.html` by double-clicking blocks `fetch()` of `products.json`.

### Tailwind setup

`tailwind.config.js` must scan both files, because many classes are written inside `script.js`:

```js
Module.exports = {
  Content: [“./index.html”, “./script.js”],
  Theme: { extend: {} },
  Plugins: [],
};
```

`input.css` contains:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## How It Works

1. `script.js` fetches `products.json` and builds one card per product.
2. Each card has a `data-name` attribute so the page can match it to its cart entry.
3. Clicking **Add to Cart** (or `+`) calls `addToCart()`, and `−` calls `decreaseQty()`.
4. `renderCart()` redraws the cart panel, the item count and the total, then calls `updateCards()` to show or hide the quantity controls and the rose image border.
5. **Confirm Order** fills the popup with the current cart. **Start New Order** empties the cart.

## Product Data Format

Each item in `products.json` looks like this:

```json
{
  “image”: {
    “thumbnail”: “./assets/images/image-waffle-thumbnail.jpg”,
    “mobile”: “./assets/images/image-waffle-mobile.jpg”,
    “tablet”: “./assets/images/image-waffle-tablet.jpg”,
    “desktop”: “./assets/images/image-waffle-desktop.jpg”
  },
  “name”: “Waffle with Berries”,
  “category”: “Waffle”,
  “price”: 6.5
}
```

## Troubleshooting

| Problem | Likely cause |
	
| Cards do not appear | Page not opened through Live Server, or wrong element ID (`product-container`) |
| Tailwind classes do not apply | Watch command not running, or `script.js` missing from `content` in `tailwind.config.js` |
| `Cannot read properties of null` | An ID or class in `script.js` does not match `index.html` (for example `cart-items`, `cart-count`, `cart-total`) |
| Images show a 404 | File name or folder in `products.json` does not match `assets/images` |
